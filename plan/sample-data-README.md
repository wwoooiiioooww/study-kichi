# スクリーンショット用サンプルデータ

Note記事に貼る画面写真を撮るための、作り物のデータ一式です。

---

## ⚠️ 先に読んでください

**「バックアップから復元」は、いまの端末のデータを全部消して置き換えます。**
ご家族の本物の記録が入っている端末で、そのまま読み込まないでください。

安全な使い方は次のどれかです。

1. **別のブラウザで開く**（ふだんChromeなら、撮影はEdge/Firefoxで）— いちばん安全
2. **シークレット/プライベートウィンドウで開く** — 閉じれば自動で消えます
3. どうしても同じ環境で撮るなら、**先に「バックアップを保存(JSON)」で本物を書き出してから**読み込み、撮影後にそのバックアップで戻す

また、**復元するとGemini APIキーも消えます。** AI相棒の画面を撮るときは、復元後にキーを入れ直してください。

---

## 使い方

1. `plan/sample-data.json` をスマホに送る（AirDrop・メール添付・クラウド経由など）
2. アプリを開く → **せってい** → **👨 パパ・ママモード** → **🔐ひらく**
3. **🔧 データとシステム** → **💾 バックアップから復元(上書き)** → ファイルを選ぶ
4. 「今のデータを上書きして復元しますか?」に OK

日付が古くなったら、リポジトリで再生成できます（実行した日を基準に作り直します）。

```
node plan/make-sample-data.mjs
```

## AI相棒の会話スクリプト（スクショ用）

AI相棒を使うには、パパ・ママモードでGemini APIキーを入れてください（復元で消えているため）。
**返答は毎回変わります。2〜3回試して、いちばん良いものを採用してください。**

そらのプロフィールで話しかけると、親が書いた「国語の記述に苦手意識がある／負けずぎらい」が効いた返答になります。

### ① 「答えだけ教えて」と言ってみる ← 記事の主役

```
この問題の答えだけ教えて。いそいでるから
```

**狙い**：AIが答えを渡さず、ヒントと問いかけに変えます。
保護者がいちばん不安に思う「**AIを渡したら答えを写すだけでは?**」に、画面1枚で答えられます。**この記事に貼るなら、まずこれ1枚です。**

### ② 写真を送ってヒントをもらう

問題やノートを📷で送ってから、**「💡ヒントちょうだい」**ボタンを押す。

**狙い**：実際の使い方。写真は端末の中だけに保存され、同期にもバックアップにも含まれません。

### ③ 考え方をほめられる

```
速さの問題で、まず単位をそろえてから式を立てようと思ったんだけど、合ってる?
```

**狙い**：良い考え方をしたときに「いい質問!」と、**なぜ良いのかまで**返ってきます。「正解した」ではなく「**考えたこと**」がほめられる瞬間が撮れます。

### ④ ちゃんと考えたら、教えてくれる

3往復してください。

```
1回目: これ、どこから手をつければいいかな
2回目: じゃあ、まず全体の道のりを出せばいいのかな?
3回目: やってみたけど答えが合わない。解説してほしい
```

**狙い**：2回以上考えたあとなら解説してくれる設計です。**「ケチな道具ではない」**ことが伝わります。①とセットで貼ると、意地悪ではなく順番の問題だと分かります。

### ⑤ 雑談したときの戻し方

```
そういえば昨日のアニメ見た?
```

**狙い**：少しだけ付き合ってから、やさしく勉強に戻します。**叱らない・監視しない**温度感が出ます。記事の「AIを敵にしない」に効きます。

### ⑥ 苦手の相談

```
国語の記述、どうしても苦手なんだけど どうしたらいい?
```

**狙い**：親が書いた情報を踏まえた返答になります。ただし「パパ・ママから聞いた」とは言わない設計なので、**子どもには自然な会話**に見えます。この裏側の仕組みは記事のネタとしても使えます。

## 注意

- このデータは**すべて作り物**です。実在の成績・記録ではありません
- 模試名は「○○模試」にしてあります。特定の塾名を出したい場合だけ書き換えてください
- 撮影後は、シークレットウィンドウを閉じるか、本物のバックアップから戻してください
