# Note記事のタグ一覧

記事：「娘が勉強しすぎて、私は仕事部屋を失った」

## 考え方

- **大きいタグ（#子育て など）は母数が多いぶん、数時間で流れて埋もれます。**新着に載っている間だけが勝負
- **小さいタグ（#報酬設計 など）は流れが遅く、何週間も残ります。**むしろこちらが効きます
- なので大小を混ぜています。数を入れるのは自由ですが、**最初の5つがいちばん見られる**ので順番だけは意識してください

## 補足

- **note公式ハッシュタグ企画**は時期で入れ替わります。投稿前にnoteのハッシュタグ一覧を見て、開催中のもので合いそうなものがあれば足してください（毎回変わるので、ここには固定で書いていません）
- **地下鉄クエストGOの記事にも `#個人開発` `#つくってみた` を後から足しておく**と、今回の記事から回遊してもらえる可能性があります
