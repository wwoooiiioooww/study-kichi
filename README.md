# スタディきち ☁️

子どもの「はじめられた」を家族で応援する、家庭用の学習トラッキングPWA。

> ここは べんきょうを「やらされる」ばしょじゃないよ。
> きょう **5分だけ** でも、じぶんで はじめられたら、それが いちばん すごいこと。

小学生の姉妹とその保護者のために作られました。ビルド不要の静的サイト（単一HTML + PWA一式）で、GitHub Pages にそのまま置けます。

## 大切にしていること

1. **「やらせる」ではなく「はじめられた」を祝う** — 机に向かった時間の長さより、自分から始められた回数を数えます。だから最小単位は5分。
2. **AIを「ずるい道具」ではなく「となりの相棒」に** — 答えをすぐには教えず、ヒントと問いかけで、考える力を残したまま伴走します。
3. **がんばりは、家族に届いてはじめて意味を持つ** — 記録は家族で共有され、「承認」という形で保護者の"見てるよ"が子どもに届きます。

## おもな機能

| | |
|---|---|
| 🚀 しゅつげき | 「きち（勉強場所）」を選んでタイマー開始。写真とメモで記録 |
| ✅ 承認 | 保護者が承認すると🎰スロットが解禁。ごほうびのスイッチ |
| ⭐ ポイントと こうかんじょ | 台帳方式のポイントで、ごほうび券・きせかえテーマと交換 |
| ⚔️ さくせん会議 / ボスバトル | 週次の計画と週末テスト、リベンジリスト |
| 🤖 AI相棒 | Gemini APIで、答えを教えずヒントで伴走。写真・音声入力対応 |
| 📊 1週間レポート | AIが週の記録から、ほめる → 課題1つ → ヒント → 親に自慢する材料、を生成 |
| ☁️ かぞく同期 | 家族コードで複数端末をマージ同期（Firebase Realtime Database） |
| 🎯 特別ミッション | 保護者が臨時の課題を出して、承認で加点 |

## つかいかた

1. `index.html` / `manifest.json` / `sw.js` / アイコン3つ を、同じ階層に置いて公開します（GitHub Pages 推奨）。
2. スマホのブラウザで開き、「ホーム画面に追加」でアプリとして使えます。
3. せってい → パパ・ママモードでPINを決めます。
4. **アプリ内の「📖 はじめての方へ」を読んでください。** 保護者が知っておくべきことは、そこに7つだけまとめてあります。
5. AI相棒を使うには、Google AI Studio の無料APIキーが必要です（アプリ内に取得ガイドがあります）。かぞく同期は追加の設定なしで使えます。

データは端末内（localStorage / IndexedDB）に保存されます。写真（しゅつげき記録・メモボード・AI相棒に送ったもの）は容量のため同期・バックアップに含まれません。

かぞく同期をONにすると、なまえ・きろく・ポイント・作戦・AI相棒との会話の文章が Firebase を経由して家族の端末どうしで共有されます（PINとAPIキーと写真は端末の外に出ません）。**個人がつくったものなので、お子さまのお名前はニックネームでのご利用をおすすめしています。** OFFのままなら、データは端末の外に一切出ません。

### かぞく同期の運用（配布する場合）

同期は作者の Firebase プロジェクトを経由します。**Sparkプラン（無料）のままにしてください** — 上限に達しても自動で停止するだけで、課金は発生しません。停止しても各端末のデータは残り、アプリはローカルで動き続けます。

月に一度、Firebase Console の「使用状況」でダウンロード量を確認し、**月3GBを超えたらペイロードの削減か配布方法の見直し**を検討してください（無料枠は10GB/月）。同期ペイロードは1家族あたり約10KB（v26時点の実測）で、記録がたまると年に200〜300KBずつ増えます。

### セキュリティルール

Realtime Database のルールは [`database.rules.json`](database.rules.json) で構成管理しています。変更したら Firebase Console → Realtime Database → ルール に貼り付けて公開してください。ルートからの一覧取得を禁止し、家族コードの形式チェックと書き込みサイズの上限を設けています。

## 開発

```bash
cd test && npm install && npm test
```

jsdomベースの自動テスト。**過去に実際に起きた不具合の再発防止**を主目的に書かれています。
リリース時は `index.html` の `APP_VER` と `sw.js` の `CACHE` を必ず同時に上げてください（テストで検証されます）。
